# Bijdragen

Fijn dat je wilt bijdragen aan een project van de Nederlandse Digitale Dienst. Dit zijn de afspraken voor elke repository die geen eigen `CONTRIBUTING.md` heeft. Staat er in een repository wel een, dan gaat die voor.

## Een fout of een idee melden

Open een issue in de repository waar het om gaat. Kijk eerst of er al een issue over bestaat. Beschrijf bij een fout wat je deed, wat je verwachtte en wat er gebeurde, met de versie of de commit erbij.

Voor een kwetsbaarheid geldt een andere route. Die staat in [`SECURITY.md`](./SECURITY.md).

## Een wijziging voorstellen

1. Open bij een grotere wijziging eerst een issue, zodat je niet bouwt aan iets dat we anders voor ogen hebben.
2. Fork de repository en maak een branch voor je wijziging.
3. Houd de wijziging klein en bij één onderwerp. Draai de tests en de controles die in de README van de repository staan.
4. Open een pull request en zeg erbij wat er verandert en waarom.

Het team dat de repository beheert beoordeelt de pull request. Wat afvalt krijgt een reden in het issue of de pull request.

## Hoe we met elkaar omgaan

Dat staat in de [gedragscode](./CODE_OF_CONDUCT.md). Die geldt voor iedereen die meedoet, ook voor ons.

## Licentie van je bijdrage

Wat je bijdraagt valt onder de licentie van de repository waaraan je bijdraagt. Dat is in deze organisatie de EUPL-1.2, tenzij het `LICENSE`-bestand van de repository iets anders zegt.
