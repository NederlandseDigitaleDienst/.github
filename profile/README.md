# We helpen de overheid digitaal doorbreken

De Nederlandse Digitale Dienst (NLDD) jaagt effectieve IT-samenwerking binnen de hele overheid aan. We zijn een compacte organisatie met eigen technici in dienst, en we bouwen zelf mee. Wat we daarbij openbaar maken, staat hier.

Meer over wie we zijn lees je op [digitaledienst.overheid.nl](https://digitaledienst.overheid.nl) en in de [startnotitie](https://open.overheid.nl/details/2506fc99-0879-4b8f-a1f7-fda56e1a4fe2).

## Waar we aan bouwen

Samen met makers van andere overheidsorganisaties werken we aan systemen waar burgers en ondernemers elke dag mee te maken hebben. Die code staat voor een deel elders.

<table>
  <tr>
    <td width="33%" valign="top">

## Meedoen

- Een fout gevonden, of een idee? Open een issue in de repository waar het om gaat.
- Hoe je een wijziging voorstelt staat in [Bijdragen](https://github.com/NederlandseDigitaleDienst/.github/blob/main/CONTRIBUTING.md).
- Een kwetsbaarheid meld je vertrouwelijk. De route staat in [Beveiliging](https://github.com/NederlandseDigitaleDienst/.github/blob/main/SECURITY.md).
- We houden ons aan de [gedragscode](https://github.com/NederlandseDigitaleDienst/.github/blob/main/CODE_OF_CONDUCT.md), en vragen dat ook van jou.

Onze code valt onder de EUPL-1.2, tenzij het licentiebestand van een repository iets anders zegt. Vragen kun je stellen via opensource@minbzk.nl.

## Werken bij NLDD

We bouwen zelf. Daarom nemen we technische mensen in dienst van het Rijk en werken we niet met ingehuurde capaciteit. Of er vacatures zijn zie je op [onze website](https://digitaledienst.overheid.nl/#werken-bij).
