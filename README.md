# .github

Standaardbestanden voor alle repositories van de [Nederlandse Digitale Dienst](https://digitaledienst.overheid.nl).

GitHub toont de bestanden hieronder in elke openbare repository van de organisatie die er zelf geen heeft. Een repository met een eigen versie houdt die eigen versie.

| Bestand | Wat |
|---|---|
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | De gedragscode |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Hoe je een fout meldt of een wijziging voorstelt |
| [`SECURITY.md`](SECURITY.md) | Hoe je een kwetsbaarheid vertrouwelijk meldt |

Een `LICENSE` erft een repository niet: GitHub gebruikt het licentiebestand hier alleen voor deze repository zelf. Elke repository heeft dus een eigen `LICENSE` nodig.

## Licentie
